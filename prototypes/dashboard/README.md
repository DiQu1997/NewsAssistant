# 控制台布局原型

四个垂直频道的仪表盘布局原型，用来在写后端之前先把**呈现形态**定下来。

```
node build.mjs
```

生成 `ai-industry.html` / `semiconductor.html` / `macro-markets.html` /
`geopolitics.html`，四份都是自包含的静态页，直接用浏览器打开即可。

> **全部数据均为虚构**，仅用于验证版式与视觉编码，不代表任何真实事件、报道、
> 机构立场或市场数值。每页顶栏都有「示例数据 · 布局原型」标记。

## 文件

| 文件 | 作用 |
|---|---|
| `build.mjs` | 模板：设计 token、页面骨架、通用面板的渲染逻辑 |
| `channels.mjs` | 四个频道的标识色、演示数据、领域专属面板 |
| `*.html` | 生成产物，**不要直接改**，改了会被下次 build 覆盖 |

## 为什么这么设计

### 1. 这类数据的密度得自己造出来

worldmonitor / osiris 那类 OSINT 面板是 **sensor-driven** 的：飞机有坐标、
地震有震级，密度是数据白送的。本项目是 **semantic-driven** 的 —— 故事、断言、
实体本身既不空间也不数值。照搬地图中心布局只会得到「一张插满新闻圆点的地图」，
看起来很密，实际信息量接近于零。

所以 pipeline 必须为每个 Story 持续产出**标量**，这些标量才是可视化的燃料：

| 维度 | 含义 |
|---|---|
| velocity 动量 | 报道量的变化率（不是绝对量） |
| breadth 广度 | 多少个**独立**信源在报道 |
| consensus 共识度 | 各源 claim 的一致程度 |
| novelty 新颖度 | 今天内容里有多少是真新的 |
| uncertainty | 开放问题数量 |
| stage 阶段 | 爆发 / 升温 / 发展 / 收敛 |

**结论：dashboard 的需求要倒推进抽取层的 schema。**

### 2. 共用的是「语法」，不是「版面」

必须全局一致的是**编码含义**：色阶永远表示密度、▲▼ 永远表示方向、字符矩阵永远
表示立场、状态色永远只表示越阈。这些换一个频道就变意思，产品就废了。

应该跟着领域变的是**主舞台**，因为四个领域数据的自然形态根本不同 —— 把它们塞进
同一个骨架，等于浪费掉每个领域自带的结构：

| 频道 | 数据的自然形态 | 主舞台 |
|---|---|---|
| AI 产业 | **网络** —— 谁和谁一起出现 | 实体网络图（形状分类型，大小=活跃度） |
| 半导体 | **链条** —— 有方向的上下游 | 供应链流向图，紧张度沿链传播 |
| 宏观市场 | **成对时间序列** —— 叙事 vs 价格 | 共用一根时间轴的上下双带 |
| 地缘政治 | **分级** —— 可升可降的阶梯 | 升级阶梯，带上周→本周的移动 |

各频道的次级面板也随之不同：AI 是实体活跃度榜 + 故事流（紧凑列表，不铺热力带），
半导体是环节×时间热力 + 产能地理集中度，宏观是叙事—价格背离，地缘是走廊咽喉点
态势 + 区域×时间热力。

四份真正共用的只剩三样：**数值源带、分歧矩阵、未解问题** —— 这三个是产品的核心
价值，本来就该处处一致。

**分歧矩阵是差异化的关键** —— 两个参考项目都做不了，因为它们的数据里没有
「观点」这一层。

> 故事级的时间演变（原先的「故事热力带」）不再占任何频道的主舞台，它属于
> **下钻视图**：先在主舞台上定位到值得看的东西，再展开单个故事的时间线。

### 3. 视觉编码的取舍（都有验证依据）

- **实体类型用形状编码，不用色相。** 四个频道标识色无法同时通过全对配对的
  色觉缺陷分离度检查（紫↔蓝仅 ΔE 9.8）。与其硬凑，不如把类型交给形状 ——
  抗色觉缺陷、印刷和 forced-colors 下同样成立，颜色因此可以整个让给频道标识。
- **热力带用分位分档，不用线性也不用对数。** 日报道量动态范围只有约 10 倍：
  线性会把九成格子压进低段，对数又整个推向高段。分位分档让六档都被用上，
  突发才读得出来；代价是档距非线性，所以阈值在图例明示，精确值走 tooltip 与
  表格视图。
- **方向一律由 ▲▼ 承载，不用颜色。**「报道量上升」并不等于「好」，把
  good/critical 状态色借给方向指示会误导。状态色只保留给越阈提示条。
- **背离度比幅度不比方向。** 叙事热度是无符号强度，价格变动是有符号收益率，
  直接相减等于把两个不可比的量强行对齐 —— 这是双轴图谬误换了个形式。
- **宏观的下带三条指标归一化到基期 100，共用一根纵轴。** 原始量纲是 bp / % / 美元，
  互不可比；双纵轴会凭空造出并不存在的相关性。每条线终点直标，识别不依赖配色。
- **地缘频道刻意不画世界地图。** 手绘海岸线无法保证地理准确，位置信息由走廊 /
  咽喉点的命名承载即可，屏幕面积留给真正在变化的量 —— 级别的升降。生产版本应
  接入真实地理图层。

### 4. 无障碍

两套主题都是**选出来的**而非取反；分歧矩阵每格附字符标记，不依赖颜色单独传达；
热力带有表格视图切换；tooltip 对 hover 与键盘 focus 走同一条路径，值不被指针独占；
`prefers-reduced-motion` 下关闭全部过渡。

## 已知缺口

- 频道切换标签在原型里是惰性的（四份是独立静态页）。
- 力导向布局跑固定迭代次数后静态渲染，不做实时仿真。
- 未接任何真实数据源。
