# 视图类型库与编码语法

> 原则：**共用的是语法，不是版面。**
> 编码含义全局一致；主舞台由检测到的数据结构自动选择，不由人声明。

## 1. 编码语法（全局不变量）

这些含义换一个频道就变意思，产品就废了，因此永不改变：

- **单色顺序色阶** 永远表示密度/强度（分位分档，阈值明示在图例）
- **▲▼ 字符** 永远承载方向；颜色不承载方向（"报道量上升"≠"好"）
- **蓝↔红发散色 + 字符标记** 永远表示信源立场（灰=未表态）
- **状态色**（good/warning/serious/critical）只表示越阈，从不冒充系列色
- **形状** 编码实体类型（抗色觉缺陷；颜色让给频道标识）
- **绝不双纵轴**：量纲不同的序列归一化到基期 100 共用一根轴，终点直标
- 数字一律等宽字体；tooltip 对 hover 与键盘 focus 同路径；每图有表格视图

任何配色改动必须过 dataviz 校验器（CVD 分离度 / 对比度 / 单调性）。

## 2. 视图类型 → 触发条件

视图由数据切片里检测到的结构选择，**新领域不需要写新代码**：

| 视图 | 自动触发条件 | 典型实例 | 同构的其他领域 |
|---|---|---|---|
| **共现网络** | 实体间无向关系稠密 | AI：公司/人物/模型 | 任何"谁和谁绑一起" |
| **有向链路** | 实体间存在稳定的上下游依赖（depends 边可拓扑排序） | 半导体供应链 | 审批流程、资金流、能源输配、司法审级 |
| **有序阶梯** | 实体在少数有序状态间移动（含上期状态可算升降） | 地缘升级 | 临床分期、立法阶段、诉讼阶段 |
| **共轴时间带** | 存在可与叙事对齐的外生数值序列（≥1 条） | 宏观叙事/价格 | 疫情曲线、电价、事故率 |
| **背离榜** | 叙事强度与外生幅度可按标的配对 | 宏观 | 任何"叙事 vs 观测"域 |
| **热力矩阵** | 两个离散维度 + 强度 | 环节×时间、区域×时间 | 任意两维交叉 |
| **构成条** | 单维度按份额分解（份额和≈100%） | 产能地理集中度 | 市场份额、能源结构 |
| **排行/清单** | 单维度 + 量值 | 实体活跃度、故事流 | 到处 |
| **地理层** | 抽取到的位置属性密度高且有意义 | （未做原型；接真实图层） | 灾害、冲突、基建 |
| **分歧矩阵** | 同一断言多源立场不一 | 全频道 | **通用，核心资产** |
| **未解问题** | Story 的 open_questions 非空 | 全频道 | 通用 |

## 3. 布局策略

- 结构视图中最"重"者为主舞台（有向链路 / 共轴时间带占整行；
  网络配排行分栏；阶梯配清单分栏）
- 分歧矩阵与未解问题恒在，位置靠后
- 跨度由默认表 + 简单填充策略决定（行尾落单的面板扩展占满该行）

## 4. 刻意不做的

- **不画手绘世界地图**：海岸线无法保证准确，插满新闻圆点的地图信息量≈0。
  位置先由命名承载；地理层必须接真实图层才上。
- **不做双轴图**、不做랭cycling 色板超过校验上限、不用状态色当系列色。

## 5. 下钻层级

全库 → 频道（保存的查询） → **故事页**（单一 story 的完整状态：
时间线、claim 演变、引用与独立性、实体、未解问题） → 实体页。
频道主舞台负责"定位到值得看的东西"，故事页负责"看透一件事"。
