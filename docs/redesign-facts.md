# 事件层结构化事实与图元

2026-08-09。事件不只是一堆文章，它有**事件层的量**：台风有伤亡与登陆点，
贸易战有各国税率与谈判轮次。这一层把这些量从宣称里归拢定型，并按
表达意图选一种图把它画出来。

## 一、这不是一次新的抽取

数字本来就在宣称里。台风那条故事的正文里已经写着"北纬20.2度、17级、
920百帕"，全都作为宣称落库、带 claim id 与来源。所以这一层做的是
**归拢与定型**：把散在 40 条宣称里的同类数字识别成同一个槽位，按时间
与来源排好，并处理口径冲突。

因此它挂在 `synth` 阶段已有的那次调用上，而不是新起一个阶段——新阶段
每次调用要重付约 4 万 token 的会话底盘，加字段只付边际输出 token。
同时白拿 synth 已有的三条纪律：引用校验、增量更新（上一版喂回去）、
冷却与过期判定。

## 二、facts：类型化槽位

| 字段 | 说明 |
|---|---|
| `key` | 稳定标识，**跨轮必须复用**。改名会让图表每次刷新都重置 |
| `kind` | `single` / `disputed` / `unknown` |
| `estimates` | `disputed` 时各方口径，每个带 `source` 与 `method` |
| `gap_label` | 差额自己的名字（"高于官方通报的部分"） |
| `scope_excludes` | 该数字明确不覆盖什么 |
| `claim_ids` | 出处，缺失即丢弃 |

三条来自 NYT 超额死亡系列的做法：

1. **官方值与估计值是同级字段**，不是正文加脚注。差额是比较单位。
2. **差额本身要有名字和独立编码**——那张对比图的图例第三个键就叫
   "超出常态且高于已报告的部分"，而不是留给读者自己脑补两条线之间的空白。
3. **绝不取平均、绝不裁决**。五个疫情模型那篇甚至把"MIT 算了置信区间但
   选择不公布"写进脚注——口径差异本身就是新闻。

`kind='unknown'` 是特性不是缺陷：schema 说这类事件本该有的数还没有，
系统自动把它变成未解问题，比模型联想出来的问题更硬。

## 三、views：意图在前，图型在后

用 FT Visual Vocabulary 的方法：先判断"这个故事里哪种数据关系最重要"
（随时间变化/偏离/排名/分布/量级/部分与整体/相关/流动），再在该意图下选型。

十三种图型，全部是新闻图表里的工作马：

`numbers` `line_baseline` `bars_rolling` `swimlane` `waffle` `matrix`
`slope` `dumbbell` `bars` `stacked` `beeswarm` `stepper` `revision`

**明确不做**：桑基图、弦图、地图、不确定性锥。前三者在新闻编辑部里
近乎不存在（257 期新闻图表巡礼里"桑基"总共出现一次，"时间线"41 次）；
锥形实测有 69% 的读者读成"风暴在变大"，只有约 51% 读出它想说的意思，
飓风中心自己在 2024 年把内陆警报画到了锥的上面给它降级。

`revision`（修订史）是对"伤亡数字不断上修"的正面回答：我们没有校准过的
概率区间可画，但"这个数字被改过几次、每次谁改的"是硬事实。

## 四、规则层与提示词的分工

模型判断"数据够不够画图"并不可靠——实测 GPT-4 生成图表时渲染失败只有
3.29%，而**渲染成功却语义错误的有 21.44%**。所以：

- **图型清单、最小数据量、单位与出处的必填**写在 `_enforce_views`（代码里，可测试）
- **意图判断、标题措辞、标注选点**写在提示词（模型擅长的部分）
- **绝不让模型自审图表是否误导**——坐标轴反转骗过了 10/10 的视觉模型

最小数据量门槛（`_VIEW_GATES`）：折线/柱 ≥3 点，斜率图恰好 2 个时点且
≥3 个主体，泳道 ≥2 个主体，蜂群 ≥20 点，矩阵 ≥2×2，堆叠 ≤6 层，
华夫格总数 ≤400。达不到就不画——两个数据点的折线图比不画更糟。

## 五、渲染纪律（charts.jsx）

- **标注层比图型更重要**。"在散点图上标注三个点，我大概就懂了，
  哪怕我本来并不熟悉怎么读散点图。"标题用动词说出发现，不是给图贴标签。
- **静态、滚动即可读完**。关键信息绝不藏进 hover——"做了 tooltip 就
  假设没人会看到它"。
- **条形/面积从零起，折线不必**；圆的面积编码用 √value 定半径
  （用 value 定半径会让感知量级虚增 58%）。
- **华夫格重复单位图形，绝不缩放单个图形**；单位键与精确数字都要印出来，
  因为这种图型必然取整。人命相关用人形图标（用户 2026-08-09 拍板；
  研究提示这是一种修辞选择，有编辑部刻意改用中性方块）。
- **泳道里 `end` 为空画点，绝不画条**——那是在虚构持续时间。
- **蜂群图纵轴是防重叠的假坐标，所以纵轴必须不存在。**
- 宽高比是数据完整性参数，不由容器决定（`.viz-svg` 有 max-height 兜底）。
